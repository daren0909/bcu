# 2026-2학기 시간표 — 카드로 교체

업로드하신 `2026학년도_2학기_시간표.xlsx`(현재까지의 배정 상태)를 그대로 불러와 보여주고, `2026학년도_2학기_교과배정_교수님_.xlsx`에서 뽑은 과목 카드를 하나씩 클릭해서 원하는 칸에 배치·교체할 수 있는 도구입니다. 정적 파일이라 서버 없이 `index.html`만 열면 바로 동작합니다.

## 사용법

1. 왼쪽에서 배치하고 싶은 과목 카드를 클릭합니다(다시 클릭하면 선택 해제).
2. 오른쪽 시간표에서 그 강의를 넣고 싶은 칸을 클릭합니다 — 기존 내용이 있으면 교체됩니다.
3. 카드를 선택하지 않은 채로 채워진 칸을 클릭하면 비웁니다.
4. 상단의 "1학년 / 2학년" 버튼으로 학년을 전환합니다.
5. 화면 아래 "충돌 감지"에 같은 교수님·같은 강의실이 같은 요일·교시에 겹친 경우가 표시됩니다(참고용이며 배치를 막지는 않습니다).
6. "원본 상태로 되돌리기"를 누르면 지금까지의 편집을 지우고 업로드하신 파일의 원래 상태로 돌아갑니다.

## 알려진 제약

- **분반 정보가 없는 카드**(예: 항공서비스영어, 서비스경영 SMAT 등)는 "1-A"처럼 서브반 번호 없이 표시됩니다 — 실제로는 A1·A2 칸 모두에 배치해야 할 수 있으니, 같은 카드를 필요한 만큼 여러 칸에 반복해서 배치하시면 됩니다.
- 카드는 배치 후에도 팔레트에서 사라지지 않습니다(여러 칸에 반복 배치할 수 있도록 일부러 남겨뒀습니다).
- 2교시 연속(100분) 블록 여부는 자동으로 처리되지 않습니다 — 두 교시 모두에 같은 카드를 각각 클릭해서 배치해주세요.
- 강의실 정보가 없는 카드가 많습니다(교과배정 파일 자체에 강의실이 안 적혀 있어서입니다). 배치 후 필요하면 실제 화면에서 직접 텍스트로 수정하는 기능은 이번 버전에 없어 카드 데이터(`roster-data.js`)를 고쳐야 합니다 — 필요하시면 셀 직접 편집 기능도 추가해드릴 수 있습니다.
- 3, 4학년은 원본 파일의 표 구조가 달라 이번 버전에는 포함하지 않았습니다.
- 데이터는 이 브라우저의 localStorage에만 저장됩니다.

## GitHub Pages로 배포하기

`index.html`, `style.css`, `script.js`, `roster-data.js` 네 파일을 저장소에 올리고 Settings → Pages에서 배포하면 됩니다.
